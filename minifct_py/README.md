# MiniFCT Windows App (MVP)

Приложение Windows на Python + PySide6 для связи с ESP32-WROOM-32 по USB-UART.

## Функции
- Выбор COM-порта и скорости UART.
- Получение `INFO`.
- Ввод серийного номера, модели/ревизии изделия и оператора.
- Запуск `RUN_ALL`.
- Таблица результатов PASS/FAIL.
- Сохранение отчёта CSV (UTF-8 with BOM, удобно открывать в Excel).
- Журнал JSON-обмена.

## Совместимость прошивки
Ожидаются JSON Lines-команды и ответы, по одной JSON-строке на строку:
- Запрос: `{"cmd":"INFO"}`
- Запрос: `{"cmd":"RUN_ALL"}`
- Ответ `INFO`: объект с полями `device`, `firmware`, `tests`.
- Ответ завершения: объект с `type: "run_complete"`, `passed`, `passed_count`, `total_count`, `results`.
- Каждый элемент `results`: `test`, `passed`, `value`, `unit`, `message`.

## Установка
Рекомендуется Python 3.11 или 3.12 64-bit.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

Если PowerShell запрещает активацию venv, можно установить зависимости без активации:
```powershell
py -m pip install -r requirements.txt
py main.py
```

## Использование
1. Подключите ESP32 DevKit через USB-кабель с передачей данных.
2. В диспетчере устройств Windows найдите COM-порт (при необходимости установите драйвер CP210x или CH340).
3. Запустите приложение, обновите порты, выберите COM и нажмите «Подключить».
4. Введите серийный номер изделия и нажмите «Запустить все тесты».
5. После завершения сохраните CSV-отчёт.

## Сборка EXE (опционально)
```powershell
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --name MiniFCT main.py
```
Для первой версии можно запускать из Python; EXE лучше собирать после проверки на реальном устройстве.

## Известные ограничения MVP
- Приложение рассчитано на один JSON-ответ на команду.
- Вызов RUN_ALL синхронно читает ответ в рабочем потоке, UI не должен блокироваться.
- Если прошивка выдаёт несколько строк результата вместо одного агрегированного `run_complete`, протокол надо согласовать.
- Поле прошивки в отчёте заполняется после получения INFO (может быть пустым, если INFO не получен).
- Это MVP: перед производственным использованием нужны тесты протокола, журналирование ошибок и проверка на реальном оборудовании.
